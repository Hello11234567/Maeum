# 🌿 마음이 (Maeum)
> 개인 프로젝트 | 2026.04 ~ 개발중 🚧

Flutter 기반 AI 감정 케어 애플리케이션입니다.<br>
감정 기록과 AI 분석을 통해 사용자가 자신의 감정을 돌아볼 수 있도록 돕습니다. 일기 작성과 감정 통계 기능도 제공합니다.

MindLog 캡스톤 디자인 프로젝트에서 구현한 감정 기록 및 AI 분석 경험을 바탕으로, Spring Boot 백엔드와 연동하는 서비스로 확장하고 있습니다.

## 💡 기획 배경
감정 기록과 AI 분석을 통해 자신의 감정을 이해하고 돌아볼 수 있는 서비스를 기획했습니다.

## ✨ 주요 기능
- 🎚️ 감정기록: 기쁨, 화남, 불안, 평안, 슬픔의 감정 수치 기록
- 🤖 AI 감정 분석: 서버에 분석을 요청하고 분석 결과 및 케어 추천 확인
- 📅 감정 캘린더: 날짜별 감정 기록과 대표 이모지 확인
- 📝 일기 관리: 일기 작성 및 목록 조회
- 📊 감정 통계: 주간·월간 감정 통계 및 이전 기간 비교
- 👤 사용자 관리: 카카오 로그인, 프로필 조회 및 수정
- 🔔 알림 설정: 알림 설정 화면 및 Firebase Cloud Messaging 초기화
>일부 기능은 서버 API와의 정합성 및 실기기 연동 검증이 더 필요합니다. 현재 개발 중인 기능을 포함합니다.

## 🔧 주요 구현
### 1. 감정 기록 및 조회
- 감정 기록을 서버 API로 저장하고 날짜 기준으로 조회
- 캘린더 화면에서 날짜별 감정 데이터를 표시

### 2. AI 분석 결과 연동
- 서버의 AI 분석 API를 호출해 분석 결과 조회
- 분석 결과 화면과 캘린더에서 관련 정보 표시

### 3. 인증 및 API 통신
- 카카오 로그인 SDK를 이용한 로그인 흐름 구성
- 서버에서 발급한 Access Token과 Refresh Token을 로컬 보안 저장소에 저장
- Dio를 이용해 서버 REST API 요청 처리

### 4. 감정 통계 시각화
- 주간·월간 통계 데이터 조회
- 현재 기간과 이전 기간의 감정 데이터를 비교하는 화면 구성
